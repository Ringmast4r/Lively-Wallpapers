# community/

Wallpapers made by other people, which we run on our own desktops and recommend. They are not Net
Works work, and this repository's LICENSE does not cover them.

Each folder is one wallpaper, as its author published it, plus two things:

- the author's licence file (MIT, GPL 3.0, AGPL 3.0, CC BY-NC-SA or FUL-BYSA), which is what you may
  do with it;
- `SOURCE.md`: who made it, where it came from (repository and commit, or release), and what, if
  anything, was changed here, such as a missing thumbnail added or a file the wallpaper never
  loads left out.

`community.json` lists all 85 picks shown in the main README, including the 28 that are not in this
folder because their authors gave no licence that allows sharing; those rows link to the author.

To install one, download its zip from the
[community release](https://github.com/Ringmast4r/Lively-Wallpapers/releases/tag/community) and drop
it on the Lively Wallpaper window.

If one of these is yours and you would like it credited differently or removed, open an issue.
