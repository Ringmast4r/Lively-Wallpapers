# Clock of Clocks
A clock made of... more clocks? 

This is a wallpaper for the [Lively Wallpaper Engine](https://github.com/rocksdanister/lively).


## Install instructions:
* Open the folder where Lively stores wallpapers (usually `AppData\Local\Lively Wallpaper\Library\wallpapers`, you can also find it by right-clicking a pre-installed wallpaper and selecting `Open in file explorer`)
* Unpack the .zip file found in the releases tab there
* Restart Lively
* Select the Wallpaper within Lively
* Optionally adjust the settings of the wallpaper by right-clicking it in Lively
