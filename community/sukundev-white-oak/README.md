# Lively Wallpaper Setup

Lively Wallpaper adalah aplikasi open-source yang memungkinkan Anda menggunakan wallpaper animasi di desktop Windows Anda. Repo ini berisi konfigurasi dan tema yang digunakan untuk menciptakan tampilan desktop yang estetik dan fungsional.

## 🔧 Fitur

- Wallpaper animasi interaktif
- Monitoring sistem langsung dengan Lively Wallpaper
- Tampilan estetika cozy dengan tema minimalis
- Informasi CPU, GPU, dan RAM langsung di desktop

## 📥 Instalasi

1. **Unduh & Install Lively Wallpaper**
   - [Download dari Microsoft Store](https://apps.microsoft.com/detail/9NTM2QC6QWS7)
   - [Download dari GitHub](https://github.com/rocksdanister/lively)
2. **Tambahkan Wallpaper**
   - Unduh file wallpaper dari repo ini atau sumber lain
   - Buka Lively Wallpaper dan tambahkan file wallpaper
3. **Konfigurasi Lively Wallpaper**
   - Gunakan fitur bawaan Lively Wallpaper untuk menampilkan informasi sistem
   - Sesuaikan parameter tampilan sesuai kebutuhan

## 🎨 Tema & Konfigurasi

- **Wallpaper:** Ilustrasi cozy interior dengan nuansa hujan
- **Monitoring:** CPU, GPU, RAM, dan Network menggunakan fitur Lively Wallpaper
- **Font:** Gaya brush untuk tampilan teks
- **Jam & Tanggal:** Custom styling langsung dalam Lively Wallpaper

## ⚙️ Pengaturan Tambahan

Jika ingin mendapatkan tampilan seperti pada screenshot:

- Gunakan **taskbar transparan** dengan aplikasi [TranslucentTB](https://github.com/TranslucentTB/TranslucentTB)
- Sesuaikan **ikon desktop dan taskbar** dengan tema minimalis
