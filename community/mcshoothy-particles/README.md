# Live Particles Wallpaper

This project packages [particles.js](https://github.com/VincentGarreau/particles.js) as a Lively Wallpaper web wallpaper.

Lively Wallpaper: [rocksdanister/lively](https://github.com/rocksdanister/lively)

<img src="img/demo-1.gif" alt="Particles wallpaper demo 1" width="100%">
Credits:

- Original particles.js library by Vincent Garreau


## Use in Lively

Import this folder into Lively and apply `index.html` as the wallpaper entrypoint.

Customize the wallpaper from Lively's Customize panel using `LivelyProperties.json`.
