# Raindash

> Custom rainy window wallpaper for my own personal desktop with Lively Wallpaper. Made just for me - so no promises for reliability!

### [This is a fork of rocksdanister's original rain wallpaper.](https://github.com/rocksdanister/rain)

## Before you use:
- If you want to have weather information, setup the geoloc/geoloc.js file with the _GEOLOC_INFO object that has an
API_KEY property (from the OpenWeather API - they have up to 1 million free API calls per month) 
and also LONGITUDE/LATITUDE properties (which is your location to be retrieved with the weather info.)
- also add to the _GEOLOC_INFO: NAME for a greeting: e.g. NAME: "John Doe"
